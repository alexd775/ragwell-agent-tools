# Agent tools delivery plan

Repository created with MIT license on 2026-10-02. The accepted direction is an
independent public tools package and ordinary-user onboarding. This repository
owns implementation planning and public qualification evidence; Ragwell's backend
project retains cross-repository contract and identity decisions.

## Local pilot active

Deliver the independently installed stdio search tool, one canonical skill,
Codex/Claude Code templates, synthetic workflow examples, and truthful local guides.
Bind one API origin/project/key at process configuration. Preserve source identities,
coordinates and evidence/context distinctions; bound output, deadlines, admission
and attempts; never replay a metered search automatically.

The local candidate and its deterministic/clean installed-artifact gates are
implemented and passed on macOS across Python 3.11–3.14. Completion still requires
endpoint-only live beta authorization/failure checks and
the three sample workflows in real named Codex/Claude Code versions. Fixture HTTP
tests establish adapter behavior, not the live backend's tenant policy or a model's
task/citation/injection behavior. Track those separately in
[qualification](qualification.md) and [compatibility](../compatibility.md).

## Supported read access planned

Add source expansion and workflow-driven discovery after backend contract work.
Search needs generation-safe source references; machine discovery must expose only
current effective scopes and granted projects. Every invocation remains authorized
even when a tool is visible. Do not expose the entire REST API or bulk exports.

Link API/OpenAPI changes, generated SDK/dashboard updates, any migrations, tool
changes and relevant tenant/reindex/delete/golden gates in one delivery record.
Add dashboard installation help and public guide publishing without coupling
repository builds or duplicating the SDK's generator.

## Hosted account linking planned

Accept an OAuth grant/identity and deployment ADR first. Reuse tool schemas and
formatting through centrally authorized operations; the public package never
imports backend internals. Prefer the existing modular monolith unless a measured
operational need justifies another process.

Qualify consent, issuer/audience, redirects/PKCE, refresh/replay/revocation,
membership/access loss, caller isolation and operation budgets. Incoming OAuth
tokens must not be passed through to the API-key SDK. Qualify ChatGPT Work first,
then named hosted Codex/Claude surfaces; update beta privacy/processor information
and maintenance/monitoring/rollback behavior before activation.
[MCP authorization security](https://modelcontextprotocol.io/specification/2026-07-28/basic/authorization/security-considerations).

## User qualified beta distribution planned

Finish screenshot-based hosted guides, a choose-your-agent entry point, sample
questions, source checking, disconnect/reconnect and plain troubleshooting. Test
at least five nontechnical users without coaching; the proposed target is four
obtaining a useful cited result within 15 minutes.

Publish tested wheel/plugin artifacts through independent protected release
workflows once authorized. Public directory review, account eligibility and client
support are separate milestones. Record exact compatibility, versioned release
notes and a small maintenance/support runbook. Production launch remains subject
to separate Ragwell release gates.
